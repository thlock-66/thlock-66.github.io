# Bloom — UX Designer Portfolio

A responsive React portfolio starter inspired by botanical editorial design.

## Run locally
1. Install Node.js (LTS) if needed.
2. Unzip the project and open a terminal in this folder.
3. Run `npm install`
4. Run `npm start` and open the local URL shown in your terminal.
5. Run `npm run build` to create a production build.

## Customise before publishing
- Replace `hello@example.com` with your email address.
- Update the LinkedIn and Instagram links in `src/App.js`.
- Edit the project descriptions and tags in the `projects` array near the top of `src/App.js`.
- Replace the illustrative photography placeholders with your own images in the photography section.
- Update the page title and description in `public/index.html`.
- Google Fonts are loaded from Google Fonts; the site uses system serif fallbacks if unavailable.

## Bloom interaction
The hero's flower petals start tucked in and progressively open as the user scrolls. The effect is driven by the page scroll position and respects reduced-motion preferences. The flowers are SVG illustrations so their petal transforms remain crisp at different screen sizes.

## Notes
This uses Create React App (`react-scripts`) as requested. The portfolio content is a starter template: project case studies, contact details, and photography should be replaced with your own final content.
